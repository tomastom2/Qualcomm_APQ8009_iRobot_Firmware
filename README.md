# Qualcomm APQ8009 / iRobot Firmware Research

Repozytorium robocze do analizy firmware iRobot `sapphire-24.29.03.signed` i porównania z płytą Qualcomm APQ8009.

Oryginalny firmware nie jest commitowany bezpośrednio do historii Git. Repo zawiera narzędzia, manifesty i wyniki analizy. Pełna rozpakowana kopia może być generowana jako artefakt GitHub Actions.
